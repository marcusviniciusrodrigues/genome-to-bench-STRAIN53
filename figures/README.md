# Manuscript figures and provenance

Place the final, publication-ready figure files in this directory and update
`manifest.tsv` with the exact filename, source output, software version,
parameters and generation date. Do not commit an unlabeled draft as a final
figure.

Figure 4 uses the following fixed mapping in every location:

- **Figure 4A:** NBRIP medium, phosphate solubilisation.
- **Figure 4B:** Aleksandrov medium, potassium solubilisation.

The manuscript figure files were not supplied with the repository snapshot, so
the manifest entries remain blocked until those assets are added.
